Privacy Policy

Last updated: 2026-07-04

This privacy policy covers a small personal-use tool built to accompany the BLOOM project, which connects to the Pinterest API to read the developer's own Pinterest boards for design research purposes.

What data is accessed

With the developer's own Pinterest authorization, this tool reads board and pin data (images, titles, descriptions, and links) belonging to the developer's own Pinterest account, using the boards:read and pins:read scopes.

What is not done

This tool does not access any other Pinterest user's data, does not post, modify, or delete anything on Pinterest, and does not share any accessed data with third parties or any other service. Downloaded data is used solely as local, private reference material for design work and is not published, redistributed, or sold.

Data storage

Any downloaded images and API tokens are stored locally on the developer's own machine and are not committed to any public repository or uploaded elsewhere.

Contact

Questions about this tool can be directed via the BLOOM GitHub repository.
